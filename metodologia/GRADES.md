# Tabela de Grades

## Nota Final → Conceito

| Intervalo | Conceito | Significado |
|-----------|----------|-------------|
| **80 — 100** | **A** | Excelente — cumpriu a maioria das promessas, entregou resultados positivos nos indicadores, sem condenações relevantes |
| **60 — 79** | **B** | Bom — cumpriu boa parte das promessas, indicadores majoritariamente positivos, poucos fatos jurídicos |
| **40 — 59** | **C** | Regular — cerca de metade das promessas cumpridas, resultados mistos em indicadores, algumas penalidades |
| **20 — 39** | **D** | Ruim — minoria das promessas cumpridas, indicadores predominantemente negativos, condenações relevantes |
| **0 — 19** | **F** | Péssimo — não cumpriu a maioria das promessas, indicadores em queda, condenações graves (inelegibilidade, improbidade) |

## Critérios de Corte

| Conceito | Exigência adicional |
|----------|---------------------|
| A | C3 ≥ 80 (não pode ter condenação criminal ou improbidade) |
| B | C3 ≥ 50 |
| C | Nenhuma exigência adicional |
| D | Nenhuma exigência adicional |
| F | Aplica-se automaticamente se houver condenação por Ficha Limpa (FJ-07) |
