# Contributing to Promessômetro

## ⚠️ REGRA INVIOLÁVEL

As licenças **AGPL-3.0** (código) e **CC BY 4.0** (dados) são decisão do fundador e **NÃO PODEM** ser alteradas por contribuidores, ferramentas de IA ou pull requests sem aprovação explícita.

## Como Contribuir

### 1. Issues
- Reporte bugs com passos para reprodução
- Sugira features com justificativa clara
- Solicite correções de dados com evidências e fontes

### 2. Pull Requests
- Fork o repositório
- Crie uma branch para sua feature: `git checkout -b feature/minha-feature`
- Commit suas mudanças seguindo o padrão Conventional Commits
- Push para sua branch e abra um PR
- PRs que alterem arquivos de licença serão **rejeitados automaticamente**

### 3. Regras de Conduta
- Respeite a linguagem neutra e técnica — sem viés político
- Nunca invente dados ou evidências
- Cite sempre suas fontes

### 4. O que NÃO fazer
- ❌ Alterar `LICENSE-agpl` ou `RULES.md`
- ❌ Remover atribuição do Footer
- ❌ Mudar `"license"` no package.json
- ❌ Criar forks que removem atribuição
- ❌ Usar dados para treinar modelos de IA sem citação
